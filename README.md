
# Energy-Efficient Lighting and Air Conditioning Design for a Laboratory

## 📖 Overview
This project focuses on improving the energy efficiency and environmental comfort of a computer laboratory by redesigning its lighting and air conditioning systems. The existing setup was analyzed to identify issues such as uneven illumination and excessive energy consumption.

## ⚙️ Methodology
A detailed heat load analysis was carried out to determine the cooling requirements, and an optimized HVAC solution was proposed with appropriate safety margins. In parallel, the lighting system was redesigned using DIALux evo simulations to achieve recommended illuminance levels while minimizing energy usage.

## 🎯 Outcomes
The final solution enhances visual comfort, reduces eye strain, and improves overall system efficiency, making it suitable for real-world implementation in educational environments.

## 🛠️ Tools & Technologies
- DIALux evo  
- Heat Load Calculations  
- HVAC System Design  
- Lighting Design & Analysis
